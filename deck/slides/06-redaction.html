01 · Broad coverage

Cloud keys including Google API keys, GitHub, GitLab, Slack and Stripe tokens, JWTs, private keys, passwords and URL credentials.

02 · Everywhere it hides

Applied to message, message content, tool calls and thoughts. If it cannot run, the text is dropped.

03 · Still detectable

gemini_cli.secrets.* keeps each secret's type and length, never its value, so the exposure itself becomes an alert.
