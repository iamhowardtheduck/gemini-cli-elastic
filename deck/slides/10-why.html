Why it's awesome

Built like a real Elastic integration. Not a log dump.

Zero-touch collection

No changes to Gemini CLI, no proxy, no API key interception. If Elastic Agent is on the machine, you have coverage.

Open standards

ECS plus OpenTelemetry gen_ai.*, so it correlates with the EDR, network and OTel data you already collect.

Costs you can trust

Only one version of each model message carries token usage, so tokens are summed directly, with no deduplication.

No duplicates

Messages are re-appended as they grow. _id hashes host, file, message ID and version, so resumes never double-count.

Fail-open ML

Off by default, one toggle to enable, never blocks ingest. Same deployed models as Claude Code Transcripts: one set serves both.

Generated, not forked

tools/port_gemini.py builds the pipelines, dashboards, rules and scanner from the Claude sources; --check reports drift.
