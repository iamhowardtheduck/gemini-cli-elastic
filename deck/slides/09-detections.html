8ES|QL rules for
Elastic Security

Every alert carries the prompt that triggered it, so triage starts with intent rather than a bare shell command. The credential-file rule also watches ~/.gemini/oauth_creds.json and gcloud credentials.

  • highPrompt injection or jailbreak attempt
  • highPrompt semantically similar to malicious intent
  • highDestructive, evasion or remote-shell command run by the agent
  • medSecret exposed to the model
  • medAgent accessed a sensitive credential file
  • medCredential access or persistence command run by the agent
  • medAgent contacted a paste, webhook or tunnel service
  • medPrompt requests disabling security or changing access
