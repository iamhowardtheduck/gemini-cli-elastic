Sizing · what this cluster classifies an hour

About 1,600 to 1,800 classified prompts an hour. Zero-shot sets the number.

Capacity = zero-shot allocations × prompts per allocation per hour. The per-allocation figure depends on how many allocations share the node's cores, so size the zero-shot model first.

With few allocations, one handles about 290 prompts an hour on self-managed CPU nodes (docs/inference-tuning.md). Here 18 allocations shared one node's 24 logical CPUs with the other five models, and each got about a third of that. Not tested with Gemini CLI on Elastic Cloud; the Claude Code test there measured about 720 an hour per allocation, at the same ML cost per prompt.
