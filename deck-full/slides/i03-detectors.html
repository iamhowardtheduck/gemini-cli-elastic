Redaction · default.yml, tag redact-secrets

Nineteen detector types run on every record. Only the type and length survive.

Fixed-format tokens are matched by pattern. Free-form secrets are found next to a keyword, then checked for plausibility, so prose like "the password is wrong" is left alone.
